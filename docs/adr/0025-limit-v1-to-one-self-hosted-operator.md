# Limit the first release to one self-hosted operator

The first release is distributed as a single-operator, self-hosted tool rather than operated as a public or multi-user service: one trusted Platform Operator deploys, configures, and uses the installation, all durable data is implicitly owned by that installation, and no application-level registration, login, User, Tenant, per-user authorization, or per-user quota model is provided. The operator-facing interface is local-only by default and remote access is the operator's responsibility through a protected tunnel, VPN, or reverse proxy, while the separately exposed Worker API remains authenticated by ADR-0024; a future hosted multi-user product requires a new trust model rather than being implied by this release.

The Platform Operator configures the installation's external Model Credential in the Control Plane instead of storing per-user BYOK credentials, and the Control Plane never exposes that credential to Worker Nodes, Sandboxes, logs, or Model Context. This simplification does not trust model-generated code: Workloads remain untrusted and all existing Sandbox, resource, filesystem, network, and Control Plane/Worker isolation boundaries still apply.
