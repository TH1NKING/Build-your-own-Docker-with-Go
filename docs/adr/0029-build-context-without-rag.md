# Build Model Context without RAG

The first release assembles each Model Context deterministically from fixed system instructions and tool definitions, the current request, every step of the active Agent Run using context-safe bounded representations of Execution Results, the most recent Conversation Messages that fit the configured context budget, one rolling Conversation Summary for older history, and only explicitly referenced Attachments. Complete Messages and bounded Execution Results remain the durable source of truth in PostgreSQL; summaries are replaceable derived data, and raw captured output is not copied wholesale into model input merely because it belongs to the active Run.

The first release deliberately excludes RAG, embeddings, and vector databases because its single-operator Conversations and explicit Attachments do not yet form a knowledge corpus whose measured retrieval needs justify chunking, indexing, re-embedding, retrieval evaluation, and an additional prompt-injection surface. This decision should be revisited only when evaluations show repeated summary omissions, Conversation history routinely exceeds the useful context strategy, or the product acquires a substantial cross-Conversation or document knowledge corpus.
